# Easy PDF Vision

Easy PDF Vision is a free and open-source (FOSS) application for reading PDF documents in a simple, accessible, and privacy-respecting way.

## Features

- reading PDF documents in normal mode and **Text Reflow**, especially useful for people with low vision
- maximum privacy: no account, no general access to files, no advertising, no tracking
- ease of use
- interface designed to reduce visual fatigue

## Easy PDF Vision does not require

- registration
- an account
- Internet access
- technical or profiling cookies
- general access to all files or media on the device

The application will only have access to the document selected by the user.

# Usage

Use the ☰ button to open the menu and select **Open document** to choose the PDF you want to read, granting the related permission if requested.

In normal mode, the document is displayed while preserving the original PDF layout.

You can:

- zoom in or out using the **−** and **+** buttons
- use the two-finger gesture to zoom
- search or select text

By enabling **Text Reflow**, the text is adapted to the width of the screen to make reading easier.

In this mode:

- the **−** and **+** buttons change the text size
- the two-finger gesture changes the text size
- the text is reformatted for more continuous reading
- the original PDF layout is not preserved

**Text Reflow** may make mistakes and is especially suitable for:

- books
- articles
- magazines
- newspapers

Do not use it for documents where graphical layout is essential, for example documents containing tables, images, or complex structures, such as:

- forms
- invoices
- tax or financial documents
- medical or legal documents

Install the app:

**Get on GitHub**  
**Get on Google Play**

Easy PDF Vision is distributed as an Android application.

To install an APK downloaded from GitHub, Android may ask for permission to install applications from that source. This permission is controlled by Android and can be disabled again after installation.

# Requirements

- Android 9 or later
- a device capable of opening PDF documents supported by the Android PDF framework

No Internet connection is required to read documents.

# Privacy

Easy PDF Vision deliberately does not request broad access to device storage.

Documents are opened using the Android system document picker.

The user explicitly chooses which PDF document the application may access.

Easy PDF Vision does not contain:

- advertising
- analytics
- tracking
- telemetry
- user accounts
- cloud synchronization

The application does not require the Android Internet permission.

- change paragraph boundaries
